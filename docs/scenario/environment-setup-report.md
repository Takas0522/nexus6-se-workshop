| 概要 | 米NVIDIAは2026年7月10日、データセンター向け次世代GPU「Blackwell Ultra B300」の量産出荷開始を当初予定の2026年第2四半期から第3四半期へ延期すると発表した。製造委託先のTSMCにおける2nmプロセスノードの歩留まりが想定を15〜20%下回っていることが主因。同社のジェンスン・フアンCEOは決算説明会で「需要は極めて旺盛だが、品質基準を満たす出荷体制の構築にあと8〜10週間を要する」と述べた。市場調査会社TrendForceによれば、この延期によりHBM4メモリを含むAIアクセラレータ関連の世界出荷台数は2026年通年で約12万台の下方修正となり、クラウドサービスプロバイダーの設備投資計画にも波及する見通し。同日のNASDAQ市場でNVIDIA株は前日比4.7%下落し、フィラデルフィア半導体指数（SOX）も2.3%安となった。 |

### NEWS-2026-002: EU理事会、域内データローカライゼーション規則を最終承認——2027年1月施行で越境データ移転に新要件

| 項目 | 内容 |
|---|---|
| カテゴリ | 規制・法務 |
| 影響領域 | AIエージェント, ゲーム事業, ネットワークサービス事業 |
| 概要 | EU理事会は2026年7月8日、「欧州デジタル主権強化規則（European Digital Sovereignty Regulation, EDSR）」を賛成22カ国の特定多数決で最終承認した。同規則は2027年1月1日に施行され、EU域内で生成された個人データおよび準個人データの域外移転について、従来のGDPR標準契約条項（SCC）に加え、技術的暗号化要件と第三国データセンターの定期監査報告を義務化する。欧州委員会デジタル担当のヘンナ・ヴィルクネン上級副委員長は「年間約340億ユーロ規模の域外データ移転に透明性と安全性を確保する」と声明を発表。一方、米国商務省はこの規則が「大西洋横断データプライバシーフレームワーク（DPF）の精神に反する」との懸念を表明した。施行後6カ月の移行期間中に各企業は準拠体制の構築を求められるが、ドイツ産業連盟（BDI）の試算ではEU企業のコンプライアンス費用だけで年間推定47億ユーロに達するとされる。 |

| 項目 | 内容 |
|---|---|
| カテゴリ | インフラ・通信 |
| 影響領域 | ネットワークサービス事業, ゲーム事業, AIエージェント |
