## 4. 想定ニュースシナリオ

### NS-001: 世界的な半導体供給制約の長期化

| 項目 | 内容 |
|---|---|
| カテゴリ | サプライチェーンリスク |
| 影響領域 | 携帯電話事業, SI事業 |
| 概要 | 地政学的緊張の激化により主要半導体製造拠点の輸出規制が強化され、スマートフォン向けチップおよびサーバー用プロセッサの供給が6〜12ヶ月にわたり逼迫。端末調達コストの上昇、SI案件で使用するサーバー機器の納期遅延が見込まれる。 |

### NS-002: 改正個人情報保護法によるデータ取扱規制の厳格化

| 項目 | 内容 |
|---|---|
| カテゴリ | 法規制・コンプライアンス |
| 影響領域 | SNS事業, 携帯電話事業 |
| 概要 | 個人情報保護委員会が改正ガイドラインを施行し、ユーザー行動データの第三者提供および広告トラッキングに対する同意取得要件が大幅に強化。違反時の課徴金上限が引き上げられ、SNS広告収益モデルおよび携帯電話事業の顧客データ活用戦略に直接影響する。 |

### NS-003: 国内大手企業を標的としたランサムウェア攻撃の急増

| 項目 | 内容 |
|---|---|
| カテゴリ | サイバーセキュリティ |
| 影響領域 | 携帯電話事業, SNS事業, SI事業 |
| 概要 | 国内の通信・IT企業を標的としたランサムウェア攻撃が前年比3倍に増加。攻撃グループがVPN脆弱性を突いて社内システムを暗号化し、顧客データの流出を伴うダブルエクストーション手法が主流化。全業務領域でセキュリティ対策の緊急見直しと顧客対応が必要となる。 |
