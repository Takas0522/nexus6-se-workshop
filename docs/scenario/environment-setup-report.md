## 4. 想定ニュースシナリオ

### NS-001: 世界的半導体供給制約の深刻化

| 項目 | 内容 |
|---|---|
| カテゴリ | サプライチェーンリスク |
| 影響領域 | 携帯電話事業, SI事業 |
| 概要 | 米中間の半導体輸出規制強化により、主要チップメーカーの出荷が大幅に遅延。スマートフォン端末やサーバー機器の調達リードタイムが3〜6ヶ月に長期化し、携帯端末の在庫不足およびSIプロジェクトで使用するサーバー・ネットワーク機器の納品遅延が発生するリスクが高まっている。 |

### NS-002: 改正個人情報保護法によるデータ規制強化

| 項目 | 内容 |
|---|---|
| カテゴリ | 法規制・コンプライアンスリスク |
| 影響領域 | SNS事業, 携帯電話事業 |
| 概要 | 2026年施行の改正個人情報保護法により、ユーザー行動データの第三者提供およびターゲティング広告への利用に本人の明示的同意が必須化。SNS事業の広告収益モデルに直接影響し、携帯電話事業の顧客データ活用マーケティングにも制約が生じる。違反時の制裁金が売上高の最大4%に引き上げられた。 |

### NS-003: 国内主要クラウドリージョンへの大規模サイバー攻撃

| 項目 | 内容 |
|---|---|
| カテゴリ | サイバーセキュリティリスク |
| 影響領域 | SNS事業, SI事業, 携帯電話事業 |
| 概要 | 国内大手クラウドプロバイダーの東京リージョンがDDoS攻撃とランサムウェアの複合攻撃を受け、複数アベイラビリティゾーンで長時間サービス障害が発生。SNSプラットフォームの可用性低下、SI事業が顧客向けに構築・運用するシステムの稼働停止、携帯電話事業のオンライン契約・マイページサービスの停止リスクが顕在化した。 |
