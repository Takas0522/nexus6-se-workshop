顧客デモ用のアプリケーションやインフラストラクチャーのコードを格納するリポジトリです。
想定されたユースケースやユーザーシナリオとそれを実現するためのコードが含まれています。
このリポジトリは、顧客デモの準備や実施に役立つリソースを提供することを目的としています。

## ディレクトリ構成

- `src/`: 顧客デモ用のアプリケーションコードが含まれています。
- `infra/`: 顧客デモ用のインフラストラクチャーコードが含まれています。
- `docs/`: 顧客デモのドキュメントやガイドが含まれています。
- `README.md`: プロジェクトの概要と使用方法が記載されています。
